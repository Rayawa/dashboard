## Goal

在现有 ArkTS 工程上完成 7 项 UI/交互修复，集中在 6 个文件内，不新增依赖、不引入新权限、不改变数据接口。

## Scope / Non-goals

**范围内**
- `SStationPage.ets`：进入即加载 + 移除下拉刷新。
- `HomePage.ets`：应用总数卡片改层级三数字 + 移除下拉刷新。
- `AppsPage.ets`：修复概况/列表点击切换崩溃 + 移除下拉刷新 + 顶部回弹打开搜索。
- `SearchPage.ets`：历史顶格 + 推荐紧凑列表 + 取消搜索框自动焦点。
- `settings.ets`：用户名输入框取消自动焦点/键盘弹出。
- `InteractiveLineChart.ets`：折线图撑满容器左右 + 坐标字体放大。

**范围外（保持不变）**
- 推送式详情页 `detail/AppDetailPage.ets` 的下拉刷新、搜索页共享元素机制、接口与缓存逻辑。
- 注：issue 3/4 中的“应用详情”指底部标签页 `AppsPage`（即“应用详情”Tab），不是推送式详情页。

## Current State And Constraints

- ArkTS 严格模式：新代码禁止 `any`/`unknown`/`as` 断言；`onScrollEdge` 回调签名已确认为 `(side: Edge) => void`（SDK API 20，`Edge` 为全局枚举，无需 import）。
- 焦点相关（SDK 文档确认）：`defaultFocus(true)` 才会默认聚焦；`defaultFocus(false)` **无任何效果**。控制“非点击方式获得焦点时不弹软键盘”应使用 `enableKeyboardOnFocus(false)`（`TextInput` 与 `Search` 均支持）。
- 本环境 `arkts_check` 的 ets-loader 缺失，**编译验证统一用 `build_project`**。

## Design

### 1. S站进入即加载 + 移除下拉刷新 (`SStationPage.ets`)
根因：`Web` 被 `Refresh` 包裹后，首次挂载时 `onControllerAttached` 不稳定触发，导致 `loadUrl` 未执行；下拉刷新能加载是因为 `onRefreshing` 直接调了 `controller.loadUrl`。

- 删除 `Refresh({ refreshing: $$this.refreshing })` 及其 `.onRefreshing(...)` 包裹层，保留 `Scroll(this.scroller)` 及其内部结构。
- 删除 `@State private refreshing: boolean = false;`，以及 `onPageEnd`/`onErrorReceive` 中的 `this.refreshing = false;`。
- 保留 `onControllerAttached` 内 `setCustomUserAgent` + `loadUrl`。
- 新增 `@State private webStarted: boolean = false;`，在 `onControllerAttached` 成功 `loadUrl` 后置 `this.webStarted = true;`。
- 给 `Web` 增加 `.onAppear((): void => { if (!this.webStarted) { this.webStarted = true; try { this.controller.setCustomUserAgent(customUserAgent); this.controller.loadUrl(this.currentUrl); } catch (error) { /* warn */ } } })` 作为兜底，确保进入即加载。

### 2. 首页应用总数层级三数字卡片 (`HomePage.ets`)
展现“总数包含两部分”的层级大小关系，去掉 `+`/`=`，重写 `totalRelationCard()`：

```typescript
Column({ space: 14 }) {
    Column({ space: 4 }) {                        // 顶部：总数（大）
        Text('应用总数').fontSize(16).fontWeight(FontWeight.Bold).fontColor($r('app.color.v3_text_primary'))
        Text(formatExactCount(apps + atomic)).fontSize(34).fontWeight(FontWeight.Bold).fontColor($r('app.color.diff_content'))
    }.width('100%').alignItems(HorizontalAlign.Start)
    Row({ space: 12 }) {                          // 下方：两个组成部分（较小）
        Column({ space: 4 }) {
            Text('鸿蒙应用').fontSize(12).fontColor($r('app.color.v3_text_secondary'))
            Text(formatExactCount(apps)).fontSize(20).fontWeight(FontWeight.Bold).fontColor($r('app.color.diff_content'))
        }.layoutWeight(1).alignItems(HorizontalAlign.Start)
        Column({ space: 4 }) {
            Text('元服务').fontSize(12).fontColor($r('app.color.v3_text_secondary'))
            Text(formatExactCount(atomic)).fontSize(20).fontWeight(FontWeight.Bold).fontColor($r('app.color.v3_accent_cyan'))
        }.layoutWeight(1).alignItems(HorizontalAlign.Start)
    }.width('100%')
}
```
外层保留原卡片样式（`padding(18)`/`borderRadius(18)`/`v3_surface`/边框），并更新 `accessibilityText` 为“应用总数X，其中鸿蒙应用Y，元服务Z”。

### 3. 修复概况/列表点击切换 jscrash (`AppsPage.ets`)
根因：`HdsTitleBarSegment.onItemClicked` 在 `this.selectedIndexes = [index]` 触发重建后，立即对新（尚未挂载）的 `Scroller` 调 `currentOffset().yOffset`，未挂载时抛异常。

- 新增安全读取：
  ```typescript
  private safeOffset(scroller: Scroller): number {
      try { return scroller.currentOffset().yOffset; } catch (_error) { return 0; }
  }
  ```
- 将 `updateTitleSearch(offset: number)` 改为 `updateTitleSearch(scroller: Scroller)`，内部用 `this.safeOffset(scroller)`。
- 更新两处调用：`onItemClicked` 与 `closeSearch` 均传 `scroller`，不再直接 `scroller.currentOffset().yOffset`。

### 4. 移除下拉刷新 + 顶部回弹打开搜索 (`AppsPage.ets`, `HomePage.ets`, `SStationPage.ets`)
- **AppsPage**：
  - 删除两个 `Refresh` 包裹层与对应 `.onRefreshing(...)`；`Scroll` 直接作为 `Stack` 子节点，保留 `.width('100%').height('100%')`、`.scrollBar`、`.onDidScroll`、`.edgeEffect(EdgeEffect.Spring)`。
  - 删除 `@State overviewRefreshing`、`@State listRefreshing`、`@State overviewRefreshVersion`；`load()` finally 中 `this.listRefreshing = false;` 一并删除。
  - `OverviewSection` 调用改为不再传 `refreshVersion`/`onRefreshCompleted`（`OverviewSection.ets` 本身不改，其 props 有默认值且靠自身 `onAppear` 加载）。
  - 给概览与列表两个 `Scroll` 各加：
    ```typescript
    .onScrollEdge((side: Edge): void => {
        if (side === Edge.Top) { this.openSearch(); }
    })
    ```
    `openSearch()` 内部已有 `if (this.searchExpanded) return;` 防重复。
- **HomePage**：删除 `Refresh` 包裹与 `.onRefreshing(...)`，删除 `@State refreshing` 及其在 `load()` finally 中的 `this.refreshing = false;`。保留 `Scroll(this.scroller)` 与其余逻辑（`load(true)` 仍被“重试”按钮使用）。
- **SStationPage**：见第 1 点。

### 5. 搜索页历史顶格 + 推荐紧凑列表 (`SearchPage.ets`)
- **历史顶格**：将空态 `Scroll` 内 `Column({ space: 18 })` 顶部间距收紧为 `Column({ space: 12 })`，且确保“搜索历史”区块无额外 top padding，使历史紧贴搜索栏下方。
- **推荐紧凑列表**：新增 `@Builder private suggestionRow(value: string): void`，渲染为全宽单行 `Row`（左 `Text(value)` fontSize 15 / `v3_text_primary`、`layoutWeight(1)`；右 `Text('›')` fontSize 22 / `v3_text_secondary`），`height(46)`、`padding({left:14,right:14})`、底部分隔线 `v3_chart_grid`、`.onClick(() => this.applySuggestion(value))`。
- 将推荐区从 `Flex({ wrap }) { ForEach(tagButton) }` 改为 `Column`（含“搜索推荐”标题）+ `ForEach(this.recommendations, (value: string) => this.suggestionRow(value))`，用 `v3_surface` 容器 + 圆角包裹成列表卡片，风格与搜索结果一致。
- 历史仍保留词条样式（仅位置顶格），不改变其标签形态。

### 6. 取消搜索框与用户名框自动焦点/键盘弹出 (`SearchPage.ets`, `settings.ets`)
- **搜索框**（`SearchPage.ets`）：删除 `.defaultFocus(true)`（去掉自动聚焦）；改为追加 `.enableKeyboardOnFocus(false)`，确保非点击获得焦点时不弹软键盘（点击仍正常弹）。
- **用户名框**（`settings.ets`）：现有 `.defaultFocus(false)` 无效果，删除之；为 `TextInput` 追加 `.enableKeyboardOnFocus(false)`。

### 7. 折线图撑满容器 + 放大坐标字体 (`InteractiveLineChart.ets`)
- `dimensions()`：`left` 由 `64` 调整为 `50`，`right` 由 `18` 调整为 `8`，让绘图区向容器左右两侧拉长。
- `draw()`：`this.context.font = '13px sans-serif'` 改为 `'15px sans-serif'`；相应微调 x 轴标签纵坐标（`height - 16` → `height - 14`）与 `bottom`（`46` → `48`）避免大字被裁切。
- 若放大后 y 轴数值标签出现左端裁切，将 `left` 再回增到 52~56（数值标签右对齐绘制在 `left - 8`）。
- 该组件被 `OverviewSection` 与 `AppDetailPage` 复用，改一处即可覆盖“所有折线图”。

## Risks And Compatibility

- `onScrollEdge(Edge.Top)` 在“滚动回顶部”时也会触发，若体验过激，可加方向判定（`onScrollStart`+`onScroll` 记录上/下滚方向，仅顶部下拉时 `openSearch`）作为细化；本计划先采用直接触发 + 已有 `searchExpanded` 防重。
- 移除 `Refresh` 后，S/首页/应用详情不再有下拉刷新能力（符合需求）；HomePage 的重试按钮仍可用。
- `enableKeyboardOnFocus(false)` 只影响“点击以外方式获得焦点”，点击输入仍正常弹键盘，不影响正常输入体验。
- `InteractiveLineChart` 边距/字号调整需在真机确认 y 轴标签不裁切，必要时微调 `left`。
